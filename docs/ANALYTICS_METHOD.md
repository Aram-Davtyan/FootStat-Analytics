# Методика оценки индивидуальной эффективности футболиста

## 1. Назначение
Модуль формирует интегральную оценку эффективности игрока на основе сезонной статистики,
последних матчей и объема доступной выборки. Цель не просто вывести рейтинг, а дать
пользователю интерпретируемую аналитическую оценку:

- насколько силен игрок по сезону;
- в какой форме он находится сейчас;
- насколько устойчива эта форма;
- насколько надежен вывод по имеющимся данным;
- какой ожидается вклад в следующем матче.

## 2. Производные метрики
Для сопоставимости абсолютные показатели переводятся в формат `per90`:

`m_per90 = (m / MinutesPlayed) * 90`

Дополнительно рассчитываются относительные показатели:

- `ShotAccuracy = ShotsOnTarget / TotalShots`
- `PassAccuracy = AccuratePasses / TotalPasses`
- `GoalInvolvement_per90 = (Goals + Assists) / MinutesPlayed * 90`
- `ExpectedInvolvement_per90 = (xG + xA) / MinutesPlayed * 90`

## 3. Нелинейная нормализация
Чтобы очень большие значения не "ломали" итоговый индекс, используется экспоненциальное насыщение:

`N(x, b) = 1 - exp(-3 * x / b)`

где:

- `x` - значение метрики;
- `b` - эталонное значение для позиции;
- `N` лежит в диапазоне `[0; 1]`.

Для каждой позиционной группы (`FW`, `MF`, `DF`, `GK`) задается собственный набор метрик,
весов и штрафов.

## 4. Сезонная компонента
Сезонная сила игрока рассчитывается как:

`S_season = 100 * clamp(0.35 * R + 0.65 * sum(w_j * N_j) - 0.45 * sum(v_k * P_k))`

где:

- `R = clamp((Rating - 5.5) / 3.0)` - нормализованный базовый рейтинг;
- `w_j` - веса положительных метрик;
- `v_k` - веса штрафных метрик;
- `P_k` - нормализованные штрафы;
- `clamp` ограничивает результат диапазоном `[0; 1]`.

Примеры положительных метрик:

- для нападающих: `xG/90`, `Goals/90`, `ShotsOnTarget/90`, `Assists/90`;
- для полузащитников: `Assists/90`, `KeyPasses/90`, `AccuratePasses/90`, `Interceptions/90`;
- для защитников: `Tackles/90`, `Interceptions/90`, `AerialDuelsWon/90`, `CleanSheets/90`;
- для вратарей: `Saves/90`, `GoalsPrevented/90`, `CleanSheets/90`.

## 5. Индекс формы, устойчивости и тренда
Последние матчи учитываются через экспоненциально взвешенное среднее:

`FormRating = sum(r_t * lambda^(t-1)) / sum(lambda^(t-1))`, где `lambda = 0.72`

Далее:

- `S_form = 100 * clamp((FormRating - 5.5) / 3.0)`
- `S_stability = 100 * clamp(1 - sigma / mu)`

где `mu` и `sigma` - среднее и стандартное отклонение рейтингов последних матчей.

Тренд рассчитывается по наклону линейной регрессии:

`S_trend = 50 + 50 * clamp(beta / 0.18, -1, 1)`

где `beta` - коэффициент наклона линии тренда рейтингов.

## 6. Коэффициент надежности
Чтобы индекс не был завышен на маленькой выборке, вводится коэффициент надежности:

`K_rel = clamp(0.55 * sqrt(M / 1800) + 0.20 * (A / 20) + 0.25 * (N / 5))`

где:

- `M` - сыгранные минуты в сезоне;
- `A` - количество матчей в сезоне;
- `N` - число последних матчей, доступных для анализа формы.

## 7. Итоговый интегральный индекс
Сначала формируется агрегированное качество игрока:

`Q = 0.58 * S_season + 0.22 * S_form + 0.12 * S_stability + 0.08 * S_trend`

Итоговая оценка:

`IEI = K_rel * Q + (1 - K_rel) * 50`

Смысл формулы:

- при хорошей выборке система почти полностью доверяет рассчитанному качеству `Q`;
- при слабой выборке индекс стягивается к нейтральной зоне `50`.

Это делает модель более устойчивой и защищает от ложных выводов по 1-2 матчам.

## 8. Прогноз на следующий матч
Для прогноза ожидаемого вклада используется смесь сезонной результативности и текущей формы:

`BaseGoalsPer90 = 0.65 * xG_per90 + 0.35 * Goals_per90`

`BaseAssistsPer90 = 0.65 * xA_per90 + 0.35 * Assists_per90`

`PerformanceMultiplier = clamp((0.9 + (S_form - 50) / 250) * (0.95 + (S_trend - 50) / 500), 0.75, 1.2)`

`ExpectedGoals = BaseGoalsPer90 * ExpectedMinutes / 90 * PerformanceMultiplier`

`ExpectedAssists = BaseAssistsPer90 * ExpectedMinutes / 90 * PerformanceMultiplier`

Прогнозный индекс:

`IEI_next = 0.65 * IEI + 0.20 * S_form + 0.15 * S_trend`

## 9. Практическая полезность
Пользователь получает не одно число, а набор объяснимых показателей:

- интегральный индекс эффективности;
- сезонный вклад;
- индекс формы;
- устойчивость и надежность оценки;
- тренд последних матчей;
- сильные стороны и факторы риска;
- прогноз вклада на следующий матч.

Это соответствует теме информационно-аналитической системы, потому что система не только хранит
статистику, но и преобразует ее в аналитические выводы для принятия решений.
